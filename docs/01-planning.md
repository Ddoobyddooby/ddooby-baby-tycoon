# 01. 기획서 — 육아 타이쿤

> 버전 0.1 · 작성 2026-09-29 · 상태: MVP 기획 확정 전 초안

## 1. 한 줄 컨셉

**"새벽 3시, 아기가 운다. 뭘 원하는지 맞혀라."**
붕어빵 타이쿤식 주문-대응 루프를 육아로 옮긴 캐주얼 웹 게임.

## 2. 왜 만드나

| 구분   | 목표                                                             |
| ------ | ---------------------------------------------------------------- |
| 학습   | 게임 루프(delta time), 상태 설계, 밸런싱, PWA 배포를 끝까지 경험 |
| 결과물 | 4주 안에 **링크 하나로 누구나 플레이 가능한** 완성작             |
| 확장   | 개인 → 포트폴리오 → 지인 공개 → 웹 게임 포털/앱 수익화           |

## 3. 타겟 & 레퍼런스

- **1차 타겟**: 20~40대 부모, 예비 부모. 모바일 브라우저에서 출퇴근/틈새 시간 3~5분 플레이
- **공감 포인트**: 육아해 본 사람만 웃는 디테일 (새벽 기상, 손목 분유 온도 테스트, 트림)
- **레퍼런스**: 붕어빵 타이쿤(주문 대응 루프), Cooking Fever(업그레이드로 템포 상승), 방치형 타이쿤(성장 체감)

## 5. 게임 규칙 명세 (MVP)

| 요소        | 규칙                                                                                       | 코드 위치                      |
| ----------- | ------------------------------------------------------------------------------------------ | ------------------------------ |
| 요구        | 4종: 배고픔 🍼, 기저귀 🧷, 졸림 😴, 심심 🧸. 한 번에 1개                                   | `game/balance.ts` `NEEDS`      |
| 요구 발생   | 요구가 없을 때 포아송 과정(λ=0.5/s, 평균 2초 간격)                                         | `engine.tick`                  |
| 울음 게이지 | 0~100. 요구가 있으면 초당 14씩 상승 → 약 7초 후 폭발                                       | `engine.tick`                  |
| 준비 슬롯   | 3칸 (붕어빵 틀). 행동 버튼 = 빈 칸에서 준비 시작. 0~2.5초 덜 됨 → 6초까지 딱 좋음 → 망침   | `engine.prepare`, `prepStage`  |
| 꺼내 주기   | 슬롯 탭. 덜 됨·망침이면 요구와 상관없이 체력 −10, 슬롯 비움, 콤보 0                        | `engine.serve`                 |
| 반짝 아이템 | 준비 시작 시 8% 확률 (황금붕어빵). 보상 ×2                                                 | `engine.prepare`, `serve`      |
| 올바른 대응 | 딱 좋은 걸 맞게 줌. 보상 = 10 × max(0.3, 1 − 울음/100) × 보상배율 (× 반짝 배율)            | `engine.serve`                 |
| 틀린 대응   | 딱 좋지만 다른 걸 줌. 울음 +10 (99.9 상한), 슬롯은 그대로 남음                             | `engine.serve`                 |
| 폭발        | 요구 사라짐, 코인 −5 (0 미만 불가), 체력 −20, 폭발 횟수 기록                               | `engine.tick`                  |
| 체력        | 매일 100으로 시작 (생명 게이지). 0이 되면 그날은 바로 정산 (기진맥진)                      | `engine.tick`, `serve`         |
| 육아템      | 요구별 울음 속도 레벨당 −12% (최대 5레벨), 자장가 스피커는 보상 +20%/레벨                  | `UPGRADES`                     |
| 콤보        | 연속 정답마다 +1, 보상 배율에 +10%/콤보 가산 (최대 5콤보 = +50%). 오답·폭발·하루 종료 시 0 | `engine.serve`, `comboBonus`   |
| 하루        | 60초(`BALANCE.dayLength`). 끝나면 정산 화면, 남은 요구는 페널티 없이 사라짐                | `engine.tick`                  |
| 정산        | 달래준 횟수·울음 폭발·번 코인 표시. 정산 중 상점 가능. 버튼으로 다음 날                    | `engine.startNextDay`          |
| 저장        | 코인·레벨·통계·날짜만 localStorage 저장. 진행 중인 요구·슬롯·체력·하루 시계는 저장 안 함   | `store/gameStore.ts`           |

## 6. 화면 구성

```

HUD 아래 줄 = ❤️ 체력 막대 (30% 이하 빨강)

```

**비주얼 방향: "새벽 3시 아기방"** — 어둑한 남색 벽, 유일한 광원은 수유등의 노란빛. 울음이 차오르면 링이 노랑 → 빨강으로 번진다. 폰트는 Jua(제목·숫자) + Gowun Dodum(본문).

**아기 반응 (A안: 👶 이모지 + CSS 애니메이션 + 이모지 파티클)** — 표정은 바꾸지 않고 움직임과 주변 효과로 감정을 표현한다. 반복 움직임(mood)과 이벤트 반응(fx)은 다른 요소에 걸어 서로 덮어쓰지 않는다. `prefers-reduced-motion` 사용자에겐 끈다.

| 상황              | 아기 반응 (mood / fx) | 주변 효과                       |
| ----------------- | --------------------- | ------------------------------- |
| 요구 없음         | 숨쉬기                | 💤                              |
| 요구 발생         | 폴짝 (fx `need`)      | 말풍선 톡                       |
| 울음 < 40         | 꼼지락                |                                 |
| 울음 40~75        | 흔들흔들              | 💧 2개                          |
| 울음 ≥ 75         | 오열                  | 💧 4개, 링 깜빡임               |
| 정답              | 말랑 바운스 (`happy`) | 💕✨ 퍼짐                       |
| 오답              | 도리도리 (`no`)       | ❓                              |
| 울음 폭발         | 들썩 (`meltdown`)     | 💦 사방으로                     |
| 콤보              |                       | 콤보 클수록 큰 글씨, MAX 반짝임 |
| 하루 끝 (정산 중) | 기울어 잠듦           | 💤, "쿨쿨…"                     |

신호 판정: `game/fx.ts` (`fxFromTick`, `fxFromResult`). 나중에 B안(SVG 아기)으로 바꿀 때 이 구조를 그대로 쓴다.
