# 04. 밸런스 시트

> 수치 원본은 `src/game/balance.ts`. 이 문서는 **왜 그 값인지**와 **파생 지표**를 기록한다.

## 현재 값 (v0.1)

| 파라미터          | 값            | 의미                        |
| ----------------- | ------------- | --------------------------- |
| `needRatePerSec`  | 0.5           | 요구 사이 평균 2초 휴식     |
| `baseCrySpeed`    | 14 /s         | 방치 시 약 7.1초 후 폭발    |
| `wrongActionCry`  | +10           | 오답 1번 = 약 0.7초 손해    |
| `meltdownPenalty` | 5             | 보상 1회분의 절반           |
| `baseReward`      | 10            |                             |
| `minRewardRatio`  | 0.3           | 아슬아슬해도 3코인은 준다   |
| 육아템 비용       | 30 × 1.6^레벨 | 30 → 48 → 77 → 123 → 197    |
| 자장가 비용       | 80 × 2^레벨   | 80 → 160 → 320 → 640 → 1280 |

## 파생 지표 (추정)

반응 시간 1.2초 가정:

| 지표                      | 계산                   | 값                         |
| ------------------------- | ---------------------- | -------------------------- |
| 1사이클                   | 대기 2초 + 반응 1.2초  | 3.2초                      |
| 분당 해결 수              | 60 / 3.2               | ≈ 19회                     |
| 1회 보상                  | 10 × (1 − 16.8/100)    | ≈ 8코인                    |
| 분당 수익 (업그레이드 전) | 19 × 8                 | **≈ 155코인**              |
| 육아템 1종 풀업           | 30+48+77+123+197       | 475코인                    |
| 전체 풀업                 | 475 × 4 + 2480         | 4,380코인 → **약 25~30분** |
| 풀업 시 폭발까지          | 14 × (1 − 0.6) = 5.6/s | 약 17.9초                  |

## 조정 메모 (M2에서 할 일)

- 첫 업그레이드가 **12초 만에** 가능 → 너무 빠름. 첫 구매는 30~60초 플레이 후가 적당
- 요구가 1개씩만 나와서 반응 속도 외엔 실력 차가 안 남 → 하루 시스템 + 난이도 곡선으로 해결 예정
- 풀업 후 폭발이 18초 → 긴장감 소멸. 날짜별 울음 속도 증가로 상쇄
