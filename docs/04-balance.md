## 파생 지표 (추정)

반응 시간 1.2초 가정:

| 지표                      | 계산                   | 값                         |
| ------------------------- | ---------------------- | -------------------------- |
| 1사이클                   | 대기 2초 + 반응 1.2초  | 3.2초                      |
| 분당 해결 수              | 60 / 3.2               | ≈ 19회                     |
| 1회 보상                  | 10 × (1 − 16.8/100)    | ≈ 8코인                    |
| 분당 수익 (업그레이드 전) | 19 × 8                 | **≈ 155코인**              |
| 육아템 1종 풀업           | 30+48+77+123+197       | 475코인                    |
| 전체 풀업                 | 475 × 4 + 2480         | 4,380코인 → **약 25~30분** |
| 풀업 시 폭발까지          | 14 × (1 − 0.6) = 5.6/s | 약 17.9초                  |

> 준비 슬롯 도입(2026-10-14) 이후 위 추정은 아직 다시 계산하지 않았다. 요구 발생 후 준비 2.5초가 더 걸리므로
> 미리 준비해 두지 않으면 1사이클이 길어지고 1회 보상도 줄어든다. **플레이 측정 후 갱신 필요.**

## 조정 메모 (M2에서 할 일)

- 첫 업그레이드가 **12초 만에** 가능 → 너무 빠름. 첫 구매는 30~60초 플레이 후가 적당
- 요구가 1개씩만 나와서 반응 속도 외엔 실력 차가 안 남 → ~~하루 시스템~~(적용됨, 60초) + 난이도 곡선(날짜별 울음 속도 증가)으로 해결 예정
- 풀업 후 폭발이 18초 → 긴장감 소멸. 날짜별 울음 속도 증가로 상쇄
- 준비 슬롯: 울음 7.1초 중 준비 2.5초를 쓰면 반응 여유가 4.6초. 너무 빡빡하면 `prepReadyAt` 을 먼저 줄인다
- 육아템 효과(울음 속도 감소)는 그대로. 슬롯 확장·준비 시간 단축 아이템은 후보로만 둔다
