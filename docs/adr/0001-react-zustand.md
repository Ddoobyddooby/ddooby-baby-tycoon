# ADR 0001. 게임 구현에 React + Zustand 사용 (Phaser/Unity 대신)

- 상태: 채택
- 날짜: 2026-09-29

## 맥락

타이쿤 장르의 화면은 대부분 **버튼, 게이지, 숫자, 리스트**다. 물리 엔진, 충돌 판정, 대량 스프라이트가 필요 없다. 개발자는 웹 풀스택 경험이 많고 게임 엔진 경험은 없다. 목표는 4주 내 완성.

## 검토한 선택지

|                       | React + Zustand | Phaser 3                 | Unity             |
| --------------------- | --------------- | ------------------------ | ----------------- |
| 학습 비용             | 거의 없음       | 중간                     | 높음 (C#, 에디터) |
| UI 중심 게임 적합도   | 높음            | 중간 (UI 직접 그려야 함) | 과함              |
| 웹 배포 무게          | 가벼움          | 가벼움                   | 무거움 (WebGL)    |
| 스프라이트 애니메이션 | 약함            | 강함                     | 강함              |

## 결정

React + TypeScript + Zustand. 게임 규칙은 프레임워크 없는 순수 함수(`src/game/engine.ts`)로 분리한다.

## 결과

- 👍 코어 루프 재미 검증까지 가장 빠르다
- 👍 엔진이 순수 함수라 **나중에 Phaser 로 옮겨도 엔진은 그대로 재사용**된다
- 👎 파티클, 스프라이트시트 애니메이션이 많아지면 한계. 그 시점에 이 ADR 을 다시 검토한다
